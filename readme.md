## 💭 Random fact about my learning style

<div align="center">

### I ask a lot of questions.

Not because I don't understand...

**but because I want to understand what's happening underneath.**

<br>

`ping` → *why did it work?*
`nmap` → *what exactly did it discover?*
`ip route` → *where is this packet going?*
`Wireshark` → *what is actually inside the packet?*
`STP` → *why did the switch block that port?*
